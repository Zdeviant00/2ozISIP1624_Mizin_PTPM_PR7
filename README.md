## 📌 Описание

- `Debit` — списание средств со счёта
- `Credit` — пополнение счёта

## 📋 Ход работы

### ✅ Этап 1: Анализ исходного кода и обнаружение ошибок
**Дата:** 22.02.2026

При первоначальном запуске приложения обнаружены следующие проблемы:

#### 🔴 Баг №1: Логическая ошибка в методе `Debit`
**Описание:** Метод `Debit` использует оператор `+=` вместо `-=` для уменьшения баланса.

**Код с ошибкой:**
```csharp
public void Debit(double amount)
{
    // ... проверки ...
    m_balance += amount; // ❌ Ошибка: должно быть -=
}

#### ⚠️ Замечание №1: Использование типа `double` для финансовых операций
**Описание:** В коде используется тип `double` для хранения баланса счёта. Однако тип `double` реализует арифметику с плавающей точкой в двоичном формате, что приводит к накоплению погрешностей при операциях с десятичными дробями.

**Проблема:**  
Результат операций отображается как `$28.979999999999997` вместо ожидаемого `$28.98`. Это происходит потому, что десятичные дроби вроде `0.1`, `0.01` не могут быть точно представлены в двоичной системе.

### 🔧 Этап 2: Подготовка к тестированию (рефакторинг)
**Дата:** 22.02.2026

Для удобства ручного тестирования проведён минимальный рефакторинг метода `Main()`:

1. **Замена типа `double` → `decimal`** для точного отображения денежных значений
2. **Вынос параметров операций в переменные** в начале метода для быстрой смены тестовых данных без поиска по коду

**Изменённый метод `Main()`:**
```csharp
public static void Main()
{
    // === ПАРАМЕТРЫ ДЛЯ ТЕСТИРОВАНИЯ (менять только здесь) ===
    decimal initialBalance = 11.99m;  // Начальный баланс
    decimal creditAmount = 5.77m;     // Сумма пополнения (0 = пропустить)
    decimal debitAmount = 11.22m;     // Сумма списания (0 = пропустить)
    // =========================================================

    BankAccount ba = new BankAccount("Mr. Pelevin V", initialBalance);
    
    if (creditAmount > 0) ba.Credit(creditAmount);
    if (debitAmount > 0) ba.Debit(debitAmount);
    
    Console.WriteLine($"Начальный баланс: {initialBalance:C}");
    if (creditAmount > 0) Console.WriteLine($"Credit: +{creditAmount:C}");
    if (debitAmount > 0) Console.WriteLine($"Debit: -{debitAmount:C}");
    Console.WriteLine($"Текущий баланс: {ba.Balance:C}");
    Console.ReadLine();
}
